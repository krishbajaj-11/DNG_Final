Image Enhancement and Quality Metrics Using DNG Images
Overview

This repository presents an image enhancement workflow applied to DNG (RAW) images, along with objective evaluation using standard image quality metrics. The project focuses on improving visual quality through a structured enhancement pipeline and analyzing the results using quantitative measures.

The repository includes all materials used in this work, such as source code, sample input images, enhanced output images, and metric-related documentation.

To keep the repository lightweight, only a small set of representative images is uploaded while still demonstrating the complete process.

Contents of This Repository:-

1)Source code for image enhancement and evaluation

2)Sample DNG input images

3)Enhanced output images

4)Metric calculation reference
